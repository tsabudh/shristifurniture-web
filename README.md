# Shristi Furniture website

Static product-showcase site for shristifurniture.com.np, deployed with Cloudflare Workers (static assets).

- Site files: `public/` (`index.html`, `styles.css`, `main.js`)
- 3D models: `public/models/*.glb`, generated by `scripts/build-models.mjs`
- Config: `wrangler.jsonc`
- Deploy: push to `main`; Cloudflare runs `npx wrangler deploy`. Branches get preview builds.
- Local preview: `npx wrangler dev`

## 3D models

The furniture is built in code at real size (meters), so "View in your room" (AR) shows true scale.

```
npm install
npm run build:models   # rewrites public/models/*.glb, public/images/wood-grain.jpg, public/vendor/model-viewer.min.js
```

Commit the outputs; Cloudflare does not run the build. Finish swatches change the `Wood` or `Fabric`
material by name, so keep those names in sync between `scripts/build-models.mjs` and `public/main.js`.
